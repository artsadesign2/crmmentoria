# User Preferences

- **Sempre Fazer o Deploy:** Ao finalizar implementações e verificações, sempre realizar o commit e push para o repositório (`origin/main`) e acionar o pipeline de deploy/build em produção automaticamente.
- **WhatsApp Segurança:** Testes de WhatsApp devem sempre usar o número do usuário (`5511995302672`) e nunca disparar para clientes reais.
- **Vídeos Motion (Regras Mandatórias Globais):**
  - **Sem Alvo/Crosshair:** NUNCA colocar alvo, mira, retículo ou ponteiro circular flutuando/pairando sobre a tela em nenhum vídeo.
  - **Zero Transbordo de Texto:** Caixas de texto, balões de WhatsApp, cards e botões NUNCA podem transbordar texto para fora de suas bordas. Sempre usar quebra de linha automática (`wrapText`), padding generoso e dimensionamento responsivo do container.
  - **Títulos em até 3 Linhas:** Os títulos principais superiores devem ter no máximo 3 linhas bem espaçadas, sem encavalar com logotipos, emblemas ou caixas de conteúdo.
  - **Dinamismo e Transições Suaves:** Nenhuma cena deve ficar estática. Usar entradas sequenciais (staggered), contadores progressivos, micro-animações contínuas e transições elegantes entre cenas (zoom/slide/fade).
